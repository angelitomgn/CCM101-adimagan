# Laboratory Reflection

This laboratory activity gave me my first experience working with a cloud-based Linux environment using KillerCoda. At first, working through the terminal felt a little unfamiliar because most of the time I use graphical interfaces when working with a computer. However, after trying the different commands, I started to understand how Linux can be managed through the command line.

One of the things I learned was how to create a new user and give that user sudo privileges. I also learned basic commands such as `whoami`, `pwd`, `hostname`, `ls`, and `mkdir`. These commands may look simple, but I realized that they are important when managing a Linux system.

I also learned how to check information about the system, including the Linux version, kernel, CPU, memory, and disk space. This helped me understand that a cloud engineer needs to know the environment they are working with before managing or deploying services.

Another important part of the activity was creating and organizing my GitHub repository. I learned that GitHub is not only used for storing code but can also be used to document projects and keep track of technical work. Organizing my laboratory files in folders also makes it easier to find my previous activities.

Overall, this activity helped me become more comfortable with Linux, GitHub, and Markdown. I know that these are only basic skills, but they are a good starting point for the more advanced cloud computing activities that we will do later in the course.
