# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity is the first mission in my Cloud Computing course. The main purpose of the activity is to introduce me to a cloud-based Linux environment and the basic responsibilities of a cloud infrastructure engineer.

I used the KillerCoda Playground to access an Ubuntu Linux environment. I also created a user account, explored the Linux system, collected system information, created directories and Markdown files, and prepared a GitHub repository for my Cloud Computing portfolio.

## Objectives

The objectives of this laboratory activity are to:

* Access a Linux environment through KillerCoda.
* Create and use a Linux user account.
* Navigate the Linux file system.
* Gather basic system information.
* Create and organize directories and files.
* Use basic Linux commands.
* Create a professional GitHub repository.
* Document technical activities using Markdown.
* Practice using GitHub as a version-controlled portfolio.

## Activities Performed

During this laboratory activity, I first accessed the Ubuntu Linux Playground using KillerCoda. I created a new Linux user named `adimagan` and logged in using the new account.

I then checked my username, current working directory, and hostname. After that, I gathered information about the Linux distribution, kernel, CPU, memory, and available disk space.

I also created a basic directory structure inside my home directory and created an `about-me.md` Markdown file. Finally, I prepared my GitHub Cloud Computing portfolio and organized the laboratory documentation and screenshots.

## Linux Commands Used

| Command                 | Purpose                                 |
| ----------------------- | --------------------------------------- |
| `whoami`                | Displays the current username           |
| `pwd`                   | Displays the current working directory  |
| `hostname`              | Displays the hostname                   |
| `sudo adduser`          | Creates a new user                      |
| `sudo usermod -aG sudo` | Adds a user to the sudo group           |
| `su -`                  | Switches to another user                |
| `ls`                    | Lists files and directories             |
| `mkdir`                 | Creates directories                     |
| `cat`                   | Displays file contents                  |
| `nano`                  | Creates or edits text files             |
| `uname -r`              | Displays the kernel version             |
| `lscpu`                 | Displays CPU information                |
| `free -h`               | Displays memory information             |
| `df -h`                 | Displays disk space information         |
| `cat /etc/os-release`   | Displays Linux distribution information |

## Skills Learned

From this activity, I learned how to access and work with a Linux environment through a cloud-based playground. I also learned how to create a Linux user, navigate directories, check system information, and create files using the terminal.

I also gained experience in organizing technical documentation using Markdown and creating a GitHub repository for my laboratory activities. These skills are useful because Linux, Git, GitHub, and cloud platforms are commonly used in the IT industry.
