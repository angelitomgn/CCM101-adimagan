# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform, commonly called Google Cloud, is Google's cloud computing platform. It provides cloud services for computing, storage, databases, networking, artificial intelligence, machine learning, data analytics, and application development.

Google Cloud is especially known for its data, analytics, artificial intelligence, and Kubernetes technologies.

## Global Infrastructure

Google Cloud has a global infrastructure made up of regions and zones. Its current infrastructure information lists 43 regions and 130 zones.

Organizations can deploy workloads in different regions and zones depending on requirements such as performance, availability, latency, and data location.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and manage projects, virtual machines, storage, databases, networks, Kubernetes clusters, and other resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run different workloads in Google Cloud.

### 2. Cloud Storage

Cloud Storage is a managed object storage service used to store unstructured data in buckets.

### 3. Cloud SQL

Cloud SQL is a fully managed relational database service supporting databases such as MySQL, PostgreSQL, and SQL Server.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is Google's managed Kubernetes service. It can be used to deploy and manage containerized applications.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google has extensive experience in AI and provides cloud services for AI workloads.
2. **Kubernetes expertise** – Google created Kubernetes, and GKE provides a managed environment for Kubernetes applications.
3. **Data and analytics** – Google Cloud provides services designed for large-scale data processing and analytics.

## Typical Enterprise Use Cases

Google Cloud can be used for:

* Artificial intelligence and machine learning
* Big data and analytics
* Kubernetes applications
* Web applications
* Data storage
* Application modernization
* Global services
