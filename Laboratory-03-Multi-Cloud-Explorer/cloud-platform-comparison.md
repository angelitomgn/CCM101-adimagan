# Cloud Platform Comparison

## Major Cloud Platform Comparison

| Category            | AWS                                                            | Microsoft Azure                            | Google Cloud                                        |
| ------------------- | -------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------- |
| Launch Year         | 2006                                                           | 2010                                       | 2008*                                               |
| Compute Service     | Amazon EC2                                                     | Azure Virtual Machines                     | Compute Engine                                      |
| Storage Service     | Amazon S3                                                      | Azure Blob Storage                         | Cloud Storage                                       |
| Networking Service  | Amazon VPC                                                     | Azure Virtual Network                      | Virtual Private Cloud                               |
| Identity Service    | AWS IAM                                                        | Microsoft Entra ID                         | Cloud IAM                                           |
| Primary Strength    | Broad service selection and global infrastructure              | Microsoft and enterprise integration       | AI, data analytics, and Kubernetes                  |
| Ideal Organizations | Startups, enterprises, and organizations with varied workloads | Organizations using Microsoft technologies | Data, AI, analytics, and cloud-native organizations |

*Google App Engine, an early Google cloud platform service, launched in 2008.

## Questions

### 1. Which cloud provider offers the broadest range of services?

I would choose **AWS** for this category because it has a very large and diverse collection of cloud services. This makes it suitable for organizations with many different types of workloads and requirements.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the best choice for Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, and Microsoft identity technologies, making migration easier for organizations already using Microsoft's ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

I would choose **Google Cloud** for this category because Google has strong experience in artificial intelligence, data processing, and Kubernetes. Google Cloud also provides Google Kubernetes Engine (GKE), which is a managed Kubernetes service.

### 4. Which cloud platform would you personally choose and why?

Personally, I would choose **Google Cloud** because I am interested in artificial intelligence, data, and modern cloud technologies. I also find Kubernetes important for cloud-native applications, and Google Cloud provides strong services for these areas.

# Equivalent Cloud Services

| Service Category    | AWS        | Azure                          | Google Cloud                   |
| ------------------- | ---------- | ------------------------------ | ------------------------------ |
| Virtual Machine     | Amazon EC2 | Azure Virtual Machines         | Compute Engine                 |
| Object Storage      | Amazon S3  | Azure Blob Storage             | Cloud Storage                  |
| Identity Management | AWS IAM    | Microsoft Entra ID             | Cloud IAM                      |
| SQL Database        | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| Kubernetes          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Summary

AWS, Azure, and Google Cloud provide many similar categories of services, but the products have different names and features. Learning the equivalent services makes it easier to understand cloud computing because the same general requirements can often be solved using different providers.
